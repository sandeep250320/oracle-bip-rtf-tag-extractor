About v2 — RTF-like layout
Renders the RTF's tables, paragraphs, font sizes, bold/italic, and alignment. Fields appear as colored chips positioned exactly where they sit in the document (in the right cell, in the right paragraph).

Chip colors: blue = plain data field · amber = for-each loop · purple = if/choose · red = has errors · orange = has warnings.
Hover for code preview · click to expand code inline · Show all code to expand everything.

Not rendered: images, exact fonts, page headers/footers, list numbering, merged cells (approximated). This is an approximation of Word's layout, not a pixel-perfect render.
